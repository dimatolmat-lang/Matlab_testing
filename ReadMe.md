## Как читать результаты

| Метрика | Что означает |
|---|---|
| **RMS / peak** | Если разница между каналами постоянна — разное усиление/чувствительность. Если плавает — нестабильность или разные условия приёма. |
| **Задержка (кросс-корреляция)** | Постоянная задержка — физическое расстояние или задержка тракта. Меняется во времени — дрейф часов, несинхронность, разные пути распространения. |
| **Когерентность** | `> 0.9` — сигналы линейно связаны, можно доверять фазе. `< 0.7` — шум, клиппинг, нелинейность или каналы пишут разное. |
| **Разность фаз** | Линейный наклон по частоте — постоянная задержка. Ровно `180°` на всех частотах — инверсия полярности. Скачки — фазовая нестабильность. |
| **Отношение амплитуд (АЧХ)** | `0 дБ` — каналы совпадают. Подъёмы/провалы — разница АЧХ микрофонов или предусилителей. |
| **Вектоскоп** | Прямая линия — синфазно. Эллипс — сдвиг фазы. Круг — `90°`. Наклон в другую сторону — инверсия. |
