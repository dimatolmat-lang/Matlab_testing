## Как читать результаты

| Метрика | Что означает |
|---|---|
| **RMS / peak** | Если разница между каналами постоянна — разное усиление/чувствительность. Если плавает — нестабильность или разные условия приёма. |
| **Задержка (кросс-корреляция)** | Постоянная задержка — физическое расстояние или задержка тракта. Меняется во времени — дрейф часов, несинхронность, разные пути распространения. |
| **Когерентность** | `> 0.9` — сигналы линейно связаны, можно доверять фазе. `< 0.7` — шум, клиппинг, нелинейность или каналы пишут разное. |
| **Разность фаз** | Линейный наклон по частоте — постоянная задержка. Ровно `180°` на всех частотах — инверсия полярности. Скачки — фазовая нестабильность. |
| **Отношение амплитуд (АЧХ)** | `0 дБ` — каналы совпадают. Подъёмы/провалы — разница АЧХ микрофонов или предусилителей. |
| **Вектоскоп** | Прямая линия — синфазно. Эллипс — сдвиг фазы. Круг — `90°`. Наклон в другую сторону — инверсия. |

Актуально для ver. 2.0

Скрипт: Analysis_audio.m (линейная решётка, 4 микрофона, база соседей 180 мм)Требования: MATLAB R2016b+, Signal Processing ToolboxВходные файлы: channel_0_merged.wav … channel_3_merged.wav — рядом со скриптом,в порядке микрофонов слева направо (ch0 — крайний −X, ch3 — крайний +X).Рекомендация: запускать скрипт из папки с именем Угол_N — заданный уголподхватится автоматически и попадёт в отчёт.

## 1. Конвенции (обязательны к пониманию)

| Величина | Конвенция |
|---|---|
| Знак задержки τ | **τ > 0 = сигнал в старшем канале приходит РАНЬШЕ** (например, `ch2-ch1 > 0` — ch2 раньше ch1) |
| Угол θ | **0° = источник по нормали к центру решётки; +90° = сторона ch3 (+X); −90° = сторона ch0 (−X)** |
| Полярность | «совпадает» = фазы каналов равны; «ИНВЕРСИЯ» = сдвиг на 180° |
| Пары | «соседние пары» = ch0-ch1, ch1-ch2, ch2-ch3 (база 180 мм). «отн. ch0» = ch1-ch0, ch2-ch0, ch3-ch0 |

Если измеренный угол systematically зеркален заданному (задано +30, измеряется −30) —
добавить после `micPos` в блоке 0: `micPos(:,1) = -micPos(:,1);`

## 2. Физические ограничения решётки (d = 165 мм)

| Параметр | Значение | Смысл |
|---|---|---|
| d/c | **410 мкс** | максимум задержки между СОСЕДНИМИ микрофонами. Всё, что больше — артефакт |
| 3d/c (крайние ch0↔ch3) | 1443 мкс | максимум задержки между крайними |
| f_гр = c/(2d) | **1039 Гц** | выше — разность фаз соседей неоднозначна (фазовый метод не работает, в ДН появляются дифракционные лепестки) |
| Рабочая граница фазового метода | 1018 Гц (0.98·f_гр) | выше этой частоты тоны из фазовых оценок исключаются |
| Цена 1 мкс задержки соседей | ≈ 0.11° | чувствительность TDOA к углу |

## 4. Вывод в командное окно

### 4.1 Загрузка

```
ch0: 46875 Гц, 105.0 с
ch1: 46875 Гц, 105.0 с
...
```
Все fs должны совпадать, иначе ошибка. Длительности должны совпадать (± доля секунды).

### 4.2 Предупреждение сегментации

```
Warning: Разница уровень/пауза < 10 дБ — сегментация может быть ненадёжной
```
Порог «тихо/громко» близок к шуму. Сегментация при этом может быть верной —
проверяется по строке «Тонов распознано: X из Y» ниже.

### 4.3 Сегменты

```
Найдено активных сегментов: 7
```
Ожидание для полного сигнала генератора: 764 сегмента (190 частот × 4 уровня + 4 свипа);
каждая частота встречается 4 раза подряд (уровни 25/50/75/100 %).

### 4.4 Фазовый МНК (основная оценка задержек по тонам)

```
Фазовый МНК (соседние пары): задержки  +17.6 +129.8 +101.5 мкс; остатки 0.15 0.87 0.42 рад
```

| Поле | Как читать |
|---|---|
| задержки, мкс | оценка τ соседних пар. Достоверно при \|τ\| ≤ 481 мкс |
| остатки, рад | качество подгонки модели Δφ(f)=2πfτ+πs. **< 0.15 — отлично; 0.15–0.3 — терпимо; > 0.5 — пара отброшена (NaN)** |

Большой остаток = фаза между каналами НЕ линейна по частоте → электроника каналов,
отражения или сведение записи. Одна из главных диагностических строк.

### 4.5 ДИАГНОСТИКА

```
===== ДИАГНОСТИКА =====
Сегментов: 7; короче 0.4 с: 0
Длительности, с: медиана 4.20, min 4.15, max 4.20
Порог тишины: -60.7 dBFS
Тонов распознано: 7 из 7
Стабильных (<5 Гц разброс): 7, нестабильных: 0
Пиковые частоты первых сегментов, Гц:
260  360  460  660  760  860  960
Тонов ниже fLagMax=278 Гц: 1
phT NaN (пара 1): 0 из 7
Не-тонов длиннее 3 с (свипы): 0
```

| Строка | Ожидание для полного сигнала | Если нет — |
|---|---|---|
| Длительности | 2.0–2.1 с (тоны), ~10 с (свипы) | слипание сегментов → понизить порог (см. п. 9) |
| Тонов распознано | = числу сегментов-тонов | «0 из N» при «Стабильных: N» → смотрите остатки МНК |
| Пиковые частоты | сетка 100 100 100 100 110 110 … | ~50 = сетевой фон крадёт пик |
| Тонов ниже fLagMax | ≥ 8 (частоты 100–270 Гц) | GCC-диагностика по тонам будет пустой (не критично) |
| phT NaN | 0 | фазы не извлекаются — низкий SNR |
| Свипы | 4 | запись не полная |

### 4.6 Клиппинг

```
Клиппинг: сэмплов выше 0.995 FS:
  ch0: 0.0000 %
```
Норма: **0.0000 %** во всех каналах. Любое значение > 0 — перегруз,
всё, что выше (THD, чувствительность), под сомнением.

### 4.7 Задержки по свипам (если свипы есть)

```
Задержки по свипам (отн. ch0), мс: +0.0171 +0.0149 +0.0192
```
Широкополосный GCC-PHAT — **самая надёжная оценка TDOA**. Появляется только
на записи полного сигнала генератора. Превышение d/c = 481 мкс (по соседним)
→ печатается предупреждение о межканальных смещениях (сведение/электроника).

### 4.8 Ближнее поле (позиция источника)

```
Ближнее поле (по фаза-МНК тонов): x=+0.012 м, y=0.650 м, R=0.65 м, угол +1.06°, невязка 11 мкс
```

| Поле | Смысл |
|---|---|
| x, y, R | положение источника в координатах решётки (y — дистанция до линии) |
| угол | atan2(x, y) — угол из позиции; **при невязке < 30 мкс заменяет собой итоговый угол** |
| невязка | расхождение модели одного точечного источника с измеренными τ. **< 30 мкс — ок; больше — печатается предупреждение, позиции НЕ доверять** |

При угле ≈ 0° (источник по центру) дистанция по TDOA определяется плохо —
это свойство геометрии, не ошибка.

### 4.9 СВОДКА DOA

```
--- СВОДКА DOA (линейка, d=180 мм, f_гр=953 Гц) ---
Соседние задержки, мкс (tau>0 — старший канал раньше):
      пара GCC-тоны(диагн) фаза-МНК остаток свип
  ch0-ch1        ...        ...      ...     ...
  (!) GCC по одиночным тонам непригоден (нет полосы) и в оценках не используется; > 481 мкс (d/c) физически невозможны.
Полярность соседних пар (фазовый МНК):  ch0-ch1: совпадает ...
Оценки угла (дальнее поле):
  фаза-МНК, пара 1      +1.90°
  свип, пара 1          +2.05°
  ...
  ИТОГ (медиана)        +1.97°
  Задано 0°, ошибка +1.97°
```

| Колонка | Статус | Комментарий |
|---|---|---|
| GCC-тоны(диагн) | **только диагностика** | на одиночном тоне GCC-PHAT методически непригоден; сравнивается с фазой для выявления артефактов |
| фаза-МНК | основная по тонам | валидна при \|τ\| ≤ 481 мкс и остатке < 0.5 рад |
| остаток | качество | см. 4.4 |
| свип | основная широкополосная | NaN, если свипов нет |

Оценки угла должны **сходиться между собой** (расхождение > 10° → предупреждение
«итог ненадёжен»). Итог: медиана оценок, либо угол из ближнего поля (если невязка мала).

### 4.10 Итоговая СВОДКА

```
==================== СВОДКА ====================
Каналов: 4, fs = 46875 Гц, длительность 105.0 с

Чувствительность (медиана, дБ отн. ch0) и THD:
  ch0:  +0.00 дБ   THD(медиана) 0.71 %
  ...

Задержки и полярность отн. ch0 (фазовый МНК по тонам):
  ch1-ch0:  +17.6 мкс   полярность: совпадает
  ...

Шум и SNR:
  ch0: шум  -65.9 dBFS, сигнал  -54.1 dBFS, SNR  11.8 дБ
  ...

Направление на источник: +1.97° (0° = по центру, +90° = сторона ch3)
=================================================
```

Нормы:

| Метрика | Отлично | Допустимо | Проблема |
|---|---|---|---|
| THD (медиана) | < 1 % | 1–3 % | > 5 % или рост с частотой |
| Разброс чувствительности | ±1 дБ | ±3 дБ | > ±3 дБ |
| SNR | > 20 дБ | 12–20 дБ | < 12 дБ (поднять уровень) |
| Сигнал | −20…−6 dBFS | −40 dBFS | ниже −40 → печатается «Совет: поднимите уровень» |
| Задержки отн. ch0 | \|τ\| ≤ 1574 мкс (3·d/c) | — | больше = артефакт |
| Полярность | определена у всех | — | «неопределена» при малой разнице фаз ±180° |

## 7. Красные флаги и что они означают

| Симптом | Диагноз | Действие |
|---|---|---|
| GCC-тоны > 481 мкс | артефакт GCC на узкополосном сигнале | игнорировать колонку, она диагностическая |
| Равные GCC во всех парах при малых фазовых | межканальный сдвиг (сведение «merged», электроника) | проверить выравнивание каналов; контрольная эл. запись |
| Остатки МНК ~1 рад | фаза нелинейна по частоте | смотреть окно 14: тренд = электроника, хаос = отражения |
| Оценки угла расходятся > 10° | нет одного точечного источника | предупреждение печатается; итогу не доверять |
| Невязка ближнего поля > 30 мкс | модель не сходится | позиции не использовать |
| Тонов 0 из N при «Стабильных: N» | см. остатки МНК — пары отбракованы | поднять уровень записи |
| Пики ~50 Гц | сетевой фон | правка `fft_peak_freq` (исключить бины < 70 Гц) |
| Сегменты слиплись (длительность ≫ 2 с) | порог тишины высок | в блоке 6: `act = env > 10^(mu(1)+0.3*(mu(2)-mu(1)));` |

## 8. Предупреждения скрипта — полный список

1. `Частоты дискретизации файлов различаются` — фатальная ошибка, стоп.
2. `Разница уровень/пауза < 10 дБ` — сегментация на грани (проверить по диагностике).
3. `Стабильных тонов не найдено` — блоки тонов и DOA пропущены.
4. `Паузы не найдены — оценка шума пропущена` — нет SNR.
5. `ВНИМАНИЕ: задержки свипов превышают d/c — межканальные смещения?` — свипы исключены из оценок.
6. `ВНИМАНИЕ: невязка велика — данные не соответствуют одному точечному источнику` — ближнее поле недостоверно.
7. `ВНИМАНИЕ: оценки расходятся на X° — итог ненадёжен`.
8. `Оценок угла нет: нет валидных задержек`.
9. `Совет: уровень сигнала очень низкий… — поднимите уровень на 20-30 дБ`.
10. `Все задержки ~0: источник по центру` — норма для угла 0°.

## 9. Рекомендуемый порядок работы

1. Поднять уровень воспроизведения: сигнал должен быть −20…−6 dBFS, клиппинг 0 %.
2. Записать **полный сигнал генератора** (со свипами — без них нет широкополосного GCC).
3. Файлы записи (`channel_*_merged.wav`) положить в папку `Угол_N` и запустить скрипт из неё.
4. Прочитать: 4.4 (остатки) → 4.9 (сводка DOA, ошибка угла) → 4.10 (сводка каналов).
5. Повторить для серии углов −90…+90; из `analysis_results.mat` собрать таблицу
   «задан/измерен» — полная характеристика решётки.
6. Разово сделать контрольную запись (один сигнал электрически на все 4 входа) —
   её задержки = чистая электроника, вычитается из акустических.
````

Если после серии реальных прогонов захотите — могу дописать в этот же md раздел «Известные особенности нашей установки» с вашими фактическими цифрами (разброс чувствительности, типичные остатки, зависимость ошибки угла от заданного угла).
